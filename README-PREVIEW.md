# Menjalankan LaundryKu

Halaman interaktif dijalankan melalui aplikasi Next.js:

```bash
npm run dev
```

Buka `http://localhost:3000`. Halaman pemesanan tersedia di `/pesan`, sedangkan pelacakan pesanan ada di `/cek-status`.

`preview.html` adalah mockup statis lama dan tidak memuat alur aplikasi terbaru.
